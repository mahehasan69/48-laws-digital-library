# Mahe Digital Library

A browser-based PDF book reader with a page-turning interface.

## Use
1. Open the GitHub Pages site.
2. Choose a PDF from your device.
3. Read with the page-turn controls.

**Privacy:** The selected PDF is processed locally in your browser. This repository contains the reader application, not a copy of any book. Only upload or redistribute books when you have the necessary rights.

## GitHub Pages
In repository **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. The workflow deploys the site from the repository root.
